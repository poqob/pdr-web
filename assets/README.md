# Psikolojik Danışman Adayları - Web Assets

Bu paket, verilen tanıtım görsellerinden ayrıştırılmış portre görsellerini ve metinsel profil verilerini içerir.

## Dosyalar
- `profiles.json` — web sitesinde doğrudan veri kaynağı olarak kullanılabilecek profil bilgileri
- `profiles.md` — insan tarafından okunabilir içerik
- `sinem-isik.png`
- `zeynep-rana-filiz.png`
- `rumeysa-kiliclar.png`
- `edanur-kirca.png`

Portre PNG'leri şeffaf arka planlıdır ve posterlerdeki fotoğraf alanlarının şekline göre kırpılmıştır.
